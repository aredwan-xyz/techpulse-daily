**Topic:** LLM fine-tuning and RLHF
**Day #310**

RESOURCE_TITLE: State of GPT
RESOURCE_URL: https://www.youtube.com/watch?v=bZQun8Y4L2A
RESOURCE_SOURCE: YouTube (Microsoft Developer)

WHY_NOW:
As post-training techniques like DPO, PPO, and SFT form the foundation of open-weights customization, understanding the full alignment pipeline remains an essential core competency for AI engineers. Andrej Karpathy's landmark talk provides the gold-standard mental model for how raw foundation models are transformed into reliable, instruction-following assistants through RLHF.

WHAT_YOULL_LEARN:
- The four distinct stages of LLM creation: Pretraining, Supervised Fine-Tuning (SFT), Reward Modeling, and RLHF
- Why base models behave fundamentally differently from fine-tuned assistant models during inference
- Practical guidance on context window usage, sampling parameters, and prompt strategy optimization
- How RLHF shifts model output probability distributions to prioritize human alignment over raw entropy

WHO_ITS_FOR:
This presentation is tailored for software engineers and ML developers transitioning into LLM optimization and post-training. It offers the best high-level conceptual framework for anyone planning to fine-tune open-weights models for specialized production applications.

TIME_INVESTMENT:
42 minutes

BEST_QUOTE_OR_HIGHLIGHT:
"Base models do not want to answer your questions; they just want to complete documents. SFT and RLHF transform a text predictor into a helpful, harmless, and honest assistant."

NEXT_STEP:
Set up a hands-on experiment using Hugging Face's `trl` (Transformer Reinforcement Learning) library to run a small-scale Supervised Fine-Tuning (SFT) script followed by Direct Preference Optimization (DPO) on a small 1B–3B open-weights model.
