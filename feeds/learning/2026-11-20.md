RESOURCE_TITLE: State of GPT
RESOURCE_URL: https://www.youtube.com/watch?v=bZQunOUaL28
RESOURCE_SOURCE: Microsoft Build

WHY_NOW:
As modern post-training methodologies evolve toward complex reasoning and alignment pipelines, understanding the core mechanics of Supervised Fine-Tuning (SFT) and Reinforcement Learning from Human Feedback (RLHF) remains indispensable. This landmark talk provides the fundamental mental model for how raw base models are transformed into aligned, useful assistants, which is vital for any developer customizing open-weights models today.

WHAT_YOULL_LEARN:
- The four distinct stages of LLM training: Pretraining, Supervised Fine-Tuning (SFT), Reward Modeling, and RLHF.
- How loss functions and optimization objectives differ between token prediction and human preference alignment.
- Practical trade-offs of RLHF, including entropy collapse, hallucination tendencies, and model capability drift.
- Tactical recommendations for prompt engineering vs. fine-tuning based on task requirements and data availability.

WHO_ITS_FOR:
This talk is designed for software engineers and AI developers looking to build a deep, intuitive understanding of LLM post-training. It is particularly valuable for technical teams transitioning from basic API integration to custom SFT and preference-tuning pipelines.

TIME_INVESTMENT:
42 minutes

BEST_QUOTE_OR_HIGHLIGHT:
"Base models want to complete documents; fine-tuned models want to be helpful, harmless, and honest assistants. RLHF doesn't teach the model new knowledge—it directs the model toward a specific subset of its existing capabilities."
