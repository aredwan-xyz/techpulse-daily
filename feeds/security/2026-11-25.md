### Upstream Service Downtime: What to Do When Feeds Go Dark

When central vulnerability databases like NVD go down, your security monitoring shouldn't stop completely. Here is general advice for maintaining visibility during feed outages:

*   **Rely on Language-Specific Advisories:** Tools like `npm audit`, `cargo audit`, `pip-audit`, and `govulncheck` often pull directly from dedicated language ecosystem feeds (like the GitHub Advisory Database or OSV.dev), which operate independently of the NVD.
*   **Monitor Vendor Security Bulletins:** Check direct advisories for your critical infrastructure tools (e.g., AWS Security Bulletins, Docker Release Notes, or Kubernetes Security Advisories).
*   **Review Recent PRs for Silent Patches:** Many open-source maintainers patch vulnerabilities before a formal CVE is assigned. Keep lockfiles updated using automated dependency bots (e.g., Dependabot, Renovate).

---

### 🧠 Security Mindset

**Audit your dependencies locally, not just in CI.** 

Don't wait for a broken API or a CI pipeline failure to tell you a package is vulnerable. Make running your ecosystem's audit tool (e.g., `npm audit`, `pip-audit`) a routine habit before merging major feature branches or preparing releases.
