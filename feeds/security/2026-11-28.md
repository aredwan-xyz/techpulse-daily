### General Security Advice — Defensive Maintenance (CVSS N/A)
**Impact:** Unpatched dependencies, stale access tokens, and unmonitored logs quietly accumulate risk, turning minor code issues into major breaches.
**Action:** Run a dependency vulnerability scanner (like `npm audit`, `pip-audit`, or Dependabot) across your active repositories today and review any lingering high-severity alerts.

***

### Security Mindset
**Treat every environment variable and secret as if it's already public.** 
Never hardcode credentials, tokens, or internal endpoints—even in "temporary" test files or internal proof-of-concept scripts. Always use secret managers and ensure `.env` files are strictly excluded via `.gitignore`.
