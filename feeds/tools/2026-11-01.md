## What Is It?
`uv` is an extremely fast, single-binary Python package and project manager written in Rust. It serves as a unified drop-in replacement for `pip`, `pip-tools`, `virtualenv`, `poetry`, `pyenv`, and `pipx`.

## The Problem It Solves
Python tooling has notoriously suffered from fragmentation: you needed `pyenv` to install Python versions, `venv` to create environments, `pip` or `poetry` to install libraries, and `pipx` to run CLI tools. On top of that, dependency resolution and installation were agonizingly slow, bogging down CI/CD pipelines and local development loops.

## Why It's Worth 10 Minutes of Your Time
- **Blistering 10–100x performance:** Written in Rust, it aggressively leverages multithreading, global module caching, and filesystem hard links, turning multi-minute installs into sub-second operations.
- **Unified toolchain:** It seamlessly manages Python versions (`uv python install`), standalone CLI apps (`uvx`), and virtual environments under a single cohesive interface without needing external version managers.
- **Instant ephemeral script execution:** With support for PEP 723 inline script metadata, you can run isolated, self-contained single-file scripts with pinned dependencies without manually creating a virtual environment.

## Quick Start
```bash
# Install uv (macOS/Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Initialize a new project and add a package
uv init my-project && cd my-project
uv add requests

# Run the project inside its managed environment
uv run main.py
```

## Real-World Example
Execute an isolated script with automatically resolved, transient dependencies using inline metadata:

```python
# /// script
# requires-python = ">=3.11"
# dependencies = [
#     "httpx",
#     "rich",
# ]
# ///

import httpx
from rich import print

data = httpx.get("https://api.github.com/repos/astral-sh/uv").json()
print(f"[bold green]{data['name']}[/]: {data['stargazers_count']} stars")
```

Run it directly with:
```bash
uv run script.py
```
*(uv automatically downloads the required Python version, creates a temporary cached environment, installs `httpx` and `rich`, and executes the script.)*
