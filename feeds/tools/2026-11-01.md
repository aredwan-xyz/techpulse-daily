## What Is It?
`uv` is an extremely fast, single-binary Python package and project manager written in Rust by Astral (the creators of Ruff). It serves as a unified replacement for `pip`, `pip-tools`, `virtualenv`, `poetry`, and `pyenv`.

## The Problem It Solves
Python dependency management and environment setup has historically been fragmented, confusing, and agonizingly slow. Developers juggled three to four separate tools just to manage Python versions, lock dependencies, and isolate environments, often watching CI pipelines crawl while wheel dependencies resolved. `uv` consolidates the entire workflow into a single tool that executes nearly instantaneously.

## Why It's Worth 10 Minutes of Your Time
- **Absurd speed**: It resolves and installs packages 10–100x faster than `pip` and `poetry`, relying on aggressive global caching and parallelized Rust network/disk operations.
- **Python version management included**: You don't need `pyenv` anymore; `uv` automatically downloads, installs, and manages isolated Python runtimes (e.g., `uv python install 3.12`).
- **Zero-setup script runner**: You can execute self-contained Python scripts declaring their own inline dependencies without manually creating or activating a virtualenv.

## Quick Start
```bash
# Install uv (macOS/Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Initialize a project and add a dependency
uv init my-project && cd my-project
uv add requests

# Run inside the automatically managed virtualenv
uv run python main.py
```

## Real-World Example
Run a self-contained script with inline dependency declarations (PEP 723)—`uv` provisions an ephemeral environment and runs it in milliseconds:

```python
# /// script
# requires-python = ">=3.11"
# dependencies = [
#     "httpx",
#     "rich",
# ]
# ///

import httpx
from rich import print

data = httpx.get("https://api.github.com/repos/astral-sh/uv").json()
print(f"[bold green]Stars:[/bold green] {data['stargazers_count']}")
```

Run it directly from the terminal without activating a virtual environment:
```bash
uv run script.py
```
