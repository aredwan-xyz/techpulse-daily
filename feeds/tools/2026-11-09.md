## What Is It?
SigNoz is an open-source, full-stack observability platform built natively on OpenTelemetry and ClickHouse. It provides a single dashboard to view application metrics, distributed traces, and logs, acting as a self-hostable alternative to tools like Datadog and New Relic.

## The Problem It Solves
Proprietary observability vendors often hit growing teams with astronomical, unpredictable monthly bills for trace and log ingestion. On the flip side, building an open-source observability stack traditionally meant stitching together Prometheus for metrics, Jaeger for traces, and Loki for logs—leaving developers to manage three backend databases and fragmented dashboards. SigNoz unifies all telemetry data into one fast interface using a single columnar storage engine.

## Why It's Worth 10 Minutes of Your Time
1. **Native OpenTelemetry standard:** Built from the ground up to consume OpenTelemetry data directly, preventing vendor lock-in for your application instrumentation.
2. **Powered by ClickHouse:** Uses ClickHouse as its storage backend, delivering blazingly fast aggregation queries and up to 10x better data compression than ElasticSearch.
3. **Seamless correlation:** Allows you to click directly from a spike in your p99 latency graphs straight to the exact distributed trace and correlated log line in a single click.

## Quick Start
```bash
git clone -b main https://github.com/SigNoz/signoz.git && cd signoz/deploy/
./install.sh
# Access the UI at http://localhost:3301 once containers are up
```

## Real-World Example
Configuring a Node.js application to auto-instrument and send traces directly to your local SigNoz instance:

```javascript
// tracing.js - Run with `node --require ./tracing.js app.js`
const { NodeSDK } = require('@opentelemetry/sdk-node');
const { OTLPTraceExporter } = require('@opentelemetry/exporter-trace-otlp-grpc');
const { getNodeAutoInstrumentations } = require('@opentelemetry/auto-instrumentations-node');

const sdk = new NodeSDK({
  serviceName: 'order-service',
  traceExporter: new OTLPTraceExporter({
    url: 'http://localhost:4317', // SigNoz gRPC collector address
  }),
  instrumentations: [getNodeAutoInstrumentations()],
});

sdk.start();
```
