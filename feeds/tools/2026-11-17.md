# Starship

**Category:** CLI
**Link:** [https://github.com/starship/starship](https://github.com/starship/starship)

[![Repo](https://img.shields.io/badge/View_on_GitHub-181717?style=flat-square&logo=github)](
https://github.com/starship/starship)

---

## What Is It?
Starship is a minimal, blazing-fast, and infinitely customizable prompt for any shell. It shows you the information you actually care about—like your git branch, node version, or AWS profile—only when you need it.

## The Problem It Solves
Configuring your terminal shell (Bash, Zsh, Fish) usually means wrestling with messy, brittle configuration scripts or bloated themes that make your terminal sluggish. Developers waste hours piecing together git status plugins, language version indicators, and prompt decorators that inevitably break on the next update or slow down your `cd` commands. Starship replaces all of that with a single, lightning-fast binary written in Rust that works identically across every major shell.

## Why It's Worth 10 Minutes of Your Time
1. **Instant context switching:** It automatically detects what project you're in and shows relevant toolchains (Node, Rust, Python, Go, Docker) without cluttering your screen when they aren't in use.
2. **Blazing fast:** Written in Rust, it renders asynchronously so your prompt never lags, even in massive git repositories.
3. **Zero-effort consistency:** One `starship.toml` file gives you the exact same beautiful prompt whether you SSH into a remote server, open a Docker container, or use your local terminal.

## Quick Start
```bash
# Install the binary (macOS/Linux)
curl -sS https://starship.rs/install.sh | sh

# Add the init script to your shell config (~/.zshrc, ~/.bashrc, etc.)
echo 'eval "$(starship init zsh)"' >> ~/.zshrc
source ~/.zshrc
```

## Real-World Example
When you navigate into a Rust project using git, your prompt transforms automatically:
```bash
# Before entering a project directory:
➜  ~ 

# After entering a Rust git repo on branch 'main':
➜  my-project (git:main) [rust:1.75.0] 
```
*(No manual plugin installation, prompt configuration scripts, or performance hits required.)*

## Who Should Use It
✅ Perfect for: Developers who switch between multiple languages (Node, Python, Rust, Go), use Git constantly, and want a gorgeous terminal without spending a weekend configuring Zsh plugins.
⏩ Skip if: You prefer a completely blank, vanilla shell prompt or work in restricted environments where you cannot install binary tools or modify shell rc files.

## The Honest Take
Starship is arguably the best cross-shell prompt available today, trading Zsh plugin bloat for a single, blazing-fast Rust binary. While deep customization requires learning its TOML schema, out-of-the-box it just works and makes your terminal a joy to use.
