## What Is It?
Ruff is an extremely fast Python linter and code formatter written in Rust, designed to replace Flake8, Black, isort, and dozens of other tools in a single executable.

## The Problem It Solves
Python tooling has historically been slow and fragmented, forcing developers to chain together Flake8, Black, isort, and pyupgrade in their CI and pre-commit hooks. This resulted in laggy IDE feedback, long CI build times, and complex configuration files. Ruff replaces the entire patchwork with a single tool that runs 10 to 100 times faster.

## Why It's Worth 10 Minutes of Your Time
* **Instant feedback loop:** It lints and formats hundreds of thousands of lines of code in tens of milliseconds, eliminating IDE lag and CI bottlenecks.
* **Consolidates 5+ dependencies:** Replaces Black, isort, Flake8 (plus dozens of plugins like `flake8-bugbear`), and `pyupgrade` with a single `pyproject.toml` configuration.
* **Aggressive, safe auto-fixes:** Runs `ruff check --fix` to sort imports, strip unused variables, rewrite outdated syntax (like upgrading to Python 3.10+ union types), and format code without human intervention.

## Quick Start
```bash
# Install Ruff
pip install ruff

# Check for lint errors and auto-fix what's possible
ruff check --fix

# Format your codebase (Black-compatible)
ruff format
```
