## What Is It?
DuckDB is an open-source, in-process SQL OLAP (Online Analytical Processing) database engine designed for fast analytical queries. Think of it as "SQLite for data analysis"—a lightweight, zero-dependency database optimized for complex aggregations and columnar file formats.

## The Problem It Solves
Before DuckDB, running fast analytical queries on local datasets (like multi-gigabyte CSVs or Parquet files) meant either hitting Python memory limits with Pandas or setting up heavy infrastructure like Spark
