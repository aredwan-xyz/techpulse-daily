## What Is It?
Instructor is a Python library built on top of Pydantic that makes it easy to get reliable, structured data—like JSON—out of Large Language Models. Instead of crossing your fingers and crossing out bad regex, it guarantees your LLM outputs match your exact data schemas.

## The Problem It Solves
Before Instructor, developers were writing messy prompt engineering hacks, parsing markdown code blocks, and writing endless try/except loops to catch malformed JSON from LLMs. When the model inevitably missed a field or changed a data type, the whole pipeline broke. Instructor fixes this by using Pydantic to validate outputs, automatically feeding validation errors back to the LLM so it can fix its own mistakes in real-time.

## Why It's Worth 10 Minutes of Your Time
* **Automatic Self-Correction:** If the LLM generates invalid data, Instructor catches the Pydantic validation error and sends it back to the model as a prompt correction, drastically reducing runtime failures.
* **Pure Python DX:** You define your data structures using standard Pydantic classes and type hints, meaning your LLM code looks and feels like normal, type-safe application code.
* **Model Agnostic:** It works seamlessly with OpenAI, Anthropic, Cohere, Gemini, and local models via Ollama, so you aren't locked into a single AI provider.

## Quick Start
```bash
pip install instructor openai
```

```python
import instructor
from openai import OpenAI
from pydantic import BaseModel

# Enable response_model validation
client = instructor.from_openai(OpenAI())

class User(BaseModel):
    name: str
    age: int

user = client.chat.completions.create(
    model="gpt-4o-mini",
    response_model=User,
    messages=[{"role": "user", "content": "Extract: Jason is 25 years old."}],
)

print(user.name)  # Output: Jason (type: str)
```

## Real-World Example
```python
from typing import List
from pydantic import BaseModel, Field
import instructor
from openai import OpenAI

client = instructor.from_openai(OpenAI())

class SentimentAnalysis(BaseModel):
    sentiment: str = Field(description="positive, negative, or neutral")
    confidence: float = Field(ge=0.0, le=1.0)
    key_phrases: List[str]

# Guaranteed to return a valid SentimentAnalysis instance or raise a retry error
analysis = client.chat.completions.create(
    model="gpt-4o-mini",
    response_model=SentimentAnalysis,
    messages=[
        {"role": "user", "content": "The checkout flow was confusing, but support was amazing!"}
    ],
)
print(analysis.sentiment)
```

## Who Should Use It
✅ Perfect for: Developers building production AI agents, data extraction pipelines, or features that need structured JSON from unstructured text.
⏩ Skip if: You are just building a standard chat UI or writing free-form text generation apps where structure doesn't matter.

## The Honest Take
Instructor turns LLMs from unpredictable text-generators into reliable API microservices. It has a tiny learning curve if you already know Pydantic, but it completely changes how safely you can ship AI features to production.
