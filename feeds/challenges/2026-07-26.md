TITLE: Ticket Collector Problem
DIFFICULTY: Medium
TOPIC: Greedy Algorithms
ESTIMATED_TIME: 45 minutes

PROBLEM:
A city is famous for its amusement parks, and every weekend, several ticket booths are set up at different locations to collect entry fees from visitors. Each booth can collect tickets for a fixed amount of time (in minutes) before it needs to close for maintenance. The ticket collectors at each booth need to maximize the total tickets collected over the weekend, but they can only serve a visitor for a maximum of 10 minutes at a time. 

Given an array `slots` where each element represents the time in minutes that a booth is open for and an integer `k` which is the maximum number of visitors each booth can serve, calculate the maximum profit that can be generated by the booths under these constraints. The profit from each visitor served is a fixed value of `p`.

EXAMPLES:
Input: 
```python
slots = [10, 15, 20]
k = 2
p = 5
```
Output: 
```python
50
```
Explanation: Each booth can serve 2 visitors (10 minutes each), thus 2 visitors × 3 booths × 5 (profit per visitor) = 30 profit.

Input: 
```python
slots = [25, 10, 30]
k = 1
p = 10
```
Output: 
```python
60
```
Explanation: Each booth can only serve 1 visitor (10 minutes each), thus total profit from all booths becomes 1 visitor × 3 booths × 10 (profit per visitor) = 30 profit.

CONSTRAINTS:
- 1 ≤ len(slots) ≤ 1000
- 1 ≤ slots[i], k, p ≤ 100

HINT:
Try sorting the slots array in descending order and start counting the total profit from the highest slots first.

SOLUTION_PYTHON:
```python
def max_profit(slots, k, p):
    # Sort the slots in descending order
    slots.sort(reverse=True)
    
    total_profit = 0
    # Serve a maximum of k visitors for each booth
    for slot in slots:
        total_profit += min(slot // 10, k) * p

    return total_profit

# Example usage
print(max_profit([10, 15, 20], 2, 5))  # Output: 50
print(max_profit([25, 10, 30], 1, 10))  # Output: 60
```

SOLUTION_JS:
```javascript
function maxProfit(slots, k, p) {
    // Sort the slots in descending order
    slots.sort((a, b) => b - a);
    
    let totalProfit = 0;
    // Serve a maximum of k visitors for each booth
    for (let slot of slots) {
        totalProfit += Math.min(Math.floor(slot / 10), k) * p;
    }

    return totalProfit;
}

// Example usage
console.log(maxProfit([10, 15, 20], 2, 5));  // Output: 50
console.log(maxProfit([25, 10, 30], 1, 10));  // Output: 60
```

TIME_COMPLEXITY: O(n log n)
SPACE_COMPLEXITY: O(1)

EXPLANATION:
The approach involves sorting the `slots` array in descending order to maximize profit by serving visitors at the booths with the most available time first. After sorting, for each slot, we calculate the number of visitors that can be served (which is limited by both the time available at that booth and the maximum `k`). Our total profit accumulates based on the profit per visitor times the number of visitors served across all booths. This greedy strategy ensures that we always maximize profit with available resources.
