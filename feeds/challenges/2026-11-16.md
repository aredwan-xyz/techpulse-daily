TITLE: Permission Bitmask Validator
DIFFICULTY: Easy
TOPIC: Bit Manipulation
ESTIMATED_TIME: [15 minutes]

PROBLEM:
In a multi-tenant cloud application, user permissions are stored as a single integer bitmask (`permissions`). Each bit position corresponds to a specific access right:
- Bit 0 (1): Read
- Bit 1 (2): Write
- Bit 2 (4): Delete
- Bit 3 (8): Execute
- Bit 4 (16): Admin

An administrator provides a required profile represented by another integer bitmask (`required`). However, to prevent privilege escalation, the system must ensure that the user *only* possesses permissions that are part of the allowed profile, and additionally checks if the user possesses *all* mandatory bits set in a `mandatory` bitmask.

Given three integers `permissions`, `required`, and `mandatory`, return `true` if:
1. The user's `permissions` do not contain any bits outside of the `required` profile (i.e., `permissions` is a subset of `required`).
2. The user's `permissions` include all bits specified in the `mandatory` bitmask.

Otherwise, return `false`.

EXAMPLES:
Input: permissions = 11, required = 15, mandatory = 3
Output: true
Explanation: 
- `permissions` = 11 (binary 1011: Read, Write, Execute)
- `required` = 15 (binary 1111: Read, Write, Delete, Execute)
- Since 1011 is a subset of 1111, condition 1 passes.
- `mandatory` = 3 (binary 0011: Read, Write). Since user has bits 0 and 1 set, condition 2 passes.

Input: permissions = 27, required = 15, mandatory = 1
Output: false
Explanation: `permissions` = 27 (binary 11011). It has bit 4 (16) set, which is outside the `required` mask of 15 (binary 01111). Therefore, condition 1 fails.

CONSTRAINTS:
- `permissions`, `required`, `mandatory` are integers between `0` and `1023` (representing 10 bit flags).

HINT:
Think about how bitwise operators (`&`, `|`, `^`) can isolate subsets or check if specific bits are turned on. To check if `A` is a subset of `B`, what does `A & ~B` evaluate to?

SOLUTION_PYTHON:
```python
class Solution:
    def validatePermissions(self, permissions: int, required: int, mandatory: int) -> bool:
        # 1. Check if permissions has any bits not allowed in required
        # If permissions has extra bits outside required, (permissions & ~required) will be non-zero.
        if (permissions & ~required) != 0:
            return False
        
        # 2. Check if permissions includes all mandatory bits
        # If any mandatory bit is missing, (permissions & mandatory) will not equal mandatory.
        if (permissions & mandatory) != mandatory:
            return False
            
        return True
```

SOLUTION_JS:
```javascript
function validatePermissions(permissions, required, mandatory) {
    // Check if permissions contains any bits outside the required profile
    if ((permissions & ~required) !== 0) {
        return false;
    }
    
    // Check if permissions includes all mandatory bits
    if ((permissions & mandatory) !== mandatory) {
        return false;
    }
    
    return true;
}
```

TIME_COMPLEXITY: O(1)
SPACE_COMPLEXITY: O(1)

EXPLANATION:
The solution uses basic bitwise operations which execute in constant time $O(1)$. The expression `permissions & ~required` clears all bits that are permitted, leaving only the unauthorized bits; if this result is non-zero, the user has illegal permissions. The expression `permissions & mandatory` isolates the mandatory bits present in the user's permissions, and checking equality against `mandatory` ensures every required flag is active.

FOLLOW_UP:
How would you modify your solution if instead of a single user, you needed to process an array of $N$ user permission bitmasks against the same `required` and `mandatory` criteria, and return an array of boolean validation results in optimal time?
