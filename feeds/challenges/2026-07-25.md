TITLE: Minimum String Temperature
DIFFICULTY: Hard
TOPIC: Stack & Queue
ESTIMATED_TIME: 45 minutes

PROBLEM:
You are tasked with analyzing temperature measurements given as a string of integers, where each integer represents a temperature in degrees Celsius. Your goal is to efficiently find the minimum temperature that occurs after any point in the input string until the end. You can process the input string one character at a time and must maintain the order of the temperatures while doing so.

Create a class `TemperatureAnalyzer` that has the following methods:
1. `add_temperature(temperature: str)`: Takes a string representing a single temperature and stores it in the processor.
2. `get_minimum() -> str`: Returns the minimum temperature added so far as a string. If no temperatures have been added yet, return "No temperatures".

Your implementation should be efficient in terms of both time and space.

EXAMPLES:
Input: `TemperatureAnalyzer()`, `add_temperature("30")`, `add_temperature("25")`, `add_temperature("35")`, `get_minimum()`
Output: "25"
Explanation: The minimum value among the temperatures added is 25.

Input: `TemperatureAnalyzer()`, `get_minimum()`
Output: "No temperatures"
Explanation: No temperatures have been added yet.

CONSTRAINTS:
- Temperatures will always be valid string representations of integers, and will be in the range of -50 to 50 inclusive.
- You may call the `add_temperature` method up to 10^6 times.

HINT:
Think about how to maintain the order of input while efficiently retrieving the minimum temperature at any given point.

SOLUTION_PYTHON:
```python
class TemperatureAnalyzer:
    def __init__(self):
        self.temperatures = []  # This stack holds all the temperatures
        self.min_stack = []  # This stack keeps track of minimum temperatures

    def add_temperature(self, temperature: str):
        temp = int(temperature)
        self.temperatures.append(temp)
        
        # Push to min_stack if it's empty or current temperature is less than or equal to
        if not self.min_stack or temp <= self.min_stack[-1]:
            self.min_stack.append(temp)

    def get_minimum(self) -> str:
        if not self.min_stack:
            return "No temperatures"
        return str(self.min_stack[-1])  # Return the current minimum

# Time Complexity: O(1) for get_minimum, O(1) amortized for add_temperature
# Space Complexity: O(n) to store temperatures
```

SOLUTION_JS:
```javascript
class TemperatureAnalyzer {
    constructor() {
        this.temperatures = []; // Array to hold temperatures
        this.minStack = []; // Array to maintain minimum temperatures
    }

    add_temperature(temperature) {
        const temp = parseInt(temperature);
        this.temperatures.push(temp);
        
        // Push to minStack if it's empty or current temperature is less than or equal to
        if (this.minStack.length === 0 || temp <= this.minStack[this.minStack.length - 1]) {
            this.minStack.push(temp);
        }
    }

    get_minimum() {
        return this.minStack.length === 0 ? "No temperatures" : this.minStack[this.minStack.length - 1].toString();
    }
}

// Time Complexity: O(1) for get_minimum, O(1) amortized for add_temperature
// Space Complexity: O(n) to store temperatures
```

TIME_COMPLEXITY: O(1)
SPACE_COMPLEXITY: O(n)

EXPLANATION:
This approach uses two stacks: one to store the temperatures and another to track the minimum temperatures. Every time a new temperature is added, it is compared against the current minimum; if it is lower or the same, it is added to the min stack. This allows the `get_minimum` method to run in constant time, making the overall solution efficient and optimal for large inputs.
