TITLE: Consolidate Consecutive Equal Nodes
DIFFICULTY: Easy
TOPIC: Linked Lists
ESTIMATED_TIME: 15 minutes

PROBLEM:
You are monitoring a stream of system metric logs stored as a singly linked list, where each node's value represents a status value recorded at a specific interval. 

To optimize storage, write a function that consolidates consecutive nodes with **identical values** by replacing them with a single node whose value is the sum of those consolidated nodes.

Return the head of the updated linked list.

EXAMPLES:
Input: head = [2, 2, 2, 3, 1, 1, 4]
Output: [6, 3, 2, 4]
Explanation: 
- The first three nodes `[2, 2, 2]` have identical values, consolidating to `2 + 2 + 2 = 6`.
- Node `[3]` has no adjacent identical neighbors, so it remains `3`.
- The two nodes `[1, 1]` consolidate to `1 + 1 = 2`.
- Node `[4]` remains `4`.

Input: head = [5, -5, 5]
Output: [5, -5, 5]
Explanation: No adjacent nodes have identical values, so the list remains unchanged.

CONSTRAINTS:
- The number of nodes in the list is in the range `[0, 10^4]`.
- `-10^4 <= Node.val <= 10^4`

HINT:
Use a pointer to traverse the list and an inner pointer (runner) to scan ahead as long as consecutive nodes match the initial node's value. Sum these values, update the current node, and point its `next` pointer to the first non-matching node.
