TITLE: Unique Order Identifier
DIFFICULTY: Easy
TOPIC: Arrays & Strings
ESTIMATED_TIME: 15 minutes

PROBLEM:
You are developing a system for an online retail store where each order generated needs a unique identifier. The unique identifier is an alphanumeric string composed of uppercase letters and digits. However, due to the method of generating orders, you may encounter duplicate orders before a new unique identifier can be assigned. Your task is to find and return a list of unique order identifiers from the provided list of order identifiers. 

Your program should ensure that the identifiers are returned in the order they first appeared in the input list (without duplicates).

EXAMPLES:
Input: ["A123", "B456", "A123", "C789", "B456", "D012"]
Output: ["A123", "B456", "C789", "D012"]
Explanation: The unique order identifiers from the input list, in the order they first appeared, are returned without duplicates.

Input: ["X001", "Y002", "Y002", "Z003", "X001", "X001"]
Output: ["X001", "Y002", "Z003"]

CONSTRAINTS:
- The input list will have a length between 1 and 10^4.
- Each order identifier string will have a length between 1 and 20 characters consisting of uppercase letters and digits only.

HINT:
Consider using a data structure that can help you track which identifiers have already been seen.

SOLUTION_PYTHON:
```python
def unique_order_identifiers(orders):
    unique_orders = []
    seen = set()
    
    for order in orders:
        if order not in seen:
            seen.add(order)
            unique_orders.append(order)
    
    return unique_orders

# Time Complexity: O(n)
# Space Complexity: O(n)
```

SOLUTION_JS:
```javascript
function uniqueOrderIdentifiers(orders) {
    const uniqueOrders = [];
    const seen = new Set();
    
    for (const order of orders) {
        if (!seen.has(order)) {
            seen.add(order);
            uniqueOrders.push(order);
        }
    }
    
    return uniqueOrders;
}

// Time Complexity: O(n)
// Space Complexity: O(n)
```

TIME_COMPLEXITY: O(n)
SPACE_COMPLEXITY: O(n)

EXPLANATION:
The approach used is straightforward; we iterate through the input list while maintaining a set to track previously seen order identifiers. For each order, if it hasn't been seen before, we add it to both the set and the output list. This method ensures that we only pass through the list once, making it efficient and optimal.
