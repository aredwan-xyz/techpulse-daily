TITLE: Warehouse Dispatch Pairing
DIFFICULTY: Medium
TOPIC: Two Pointers
ESTIMATED_TIME: 20 minutes

PROBLEM:
An automated warehouse logistics system matches ready packages with arriving delivery drivers. You are given two 0-indexed arrays sorted in non-decreasing order:
- `packages`: where `packages[i]` represents the timestamp when the $i$-th package is ready for pickup.
- `drivers`: where `drivers[j]` represents the timestamp when the $j$-th driver arrives at the warehouse.

You are also given an integer `max_wait`. A driver `j` can pick up a package `i` if and only if the driver arrives at or after the package is ready, but within the maximum wait window:
$$\text{packages}[i] \le \text{drivers}[j] \le \text{packages}[i] + \text{max\_wait}$$

Each driver can pick up at most one package, and each package can be assigned to at most one driver. 

Return the maximum number of package-driver pairs that can be formed.

EXAMPLES:

Input: packages = [10, 20, 25], drivers = [12, 22, 35], max_wait = 5
Output: 2
Explanation: 
- Driver at 12 picks up package at 10 (10 <= 12 <= 15).
- Driver at 22 picks up package at 20 (20 <= 22 <= 25).
- Driver at 35 cannot pick up package at 25 because 35 > 25 + 5 (wait time exceeded).
Maximum valid matches = 2.

Input: packages = [5, 10, 15], drivers = [1, 2, 3], max_wait = 10
Output: 0
Explanation: 
All drivers arrive before any package is ready. No matches can be made.

CONSTRAINTS:
- $1 \le \text{packages.length}, \text{drivers.length} \le 10^5$
- $0 \le \text{packages}[i], \text{drivers}[j] \le 10^9$
- $0 \le \text{max\_wait} \le 10^9$
- `packages` and `drivers` are sorted in non-decreasing order.

HINT:
Since both arrays are sorted, use two pointers to compare the current package and current driver. If a driver arrives too early, move to the next driver. If a package has waited too long, move to the next package.

SOLUTION_PYTHON:
```python
def max_dispatches(packages: list[int], drivers: list[int], max_wait: int) -> int:
    p_ptr = 0  # Pointer for packages
    d_ptr = 0  # Pointer for drivers
    matches = 0

    while p_ptr < len(packages) and d_ptr < len(drivers):
        pkg_time = packages[p_ptr]
        drv_time = drivers[d_ptr]

        if drv_time < pkg_time:
            # Driver arrived before package is ready.
            # This driver cannot pick up this package or any subsequent package.
            d_ptr += 1
        elif drv_time > pkg_time + max_wait:
            # Package has waited longer than max_wait for this driver.
            # This package cannot be picked up by this driver or any subsequent driver.
            p_ptr += 1
        else:
            # Valid match found!
            matches += 1
            p_ptr += 1
            d_ptr += 1

    return matches
```

SOLUTION_JS:

```javascript
function maxDispatches(packages, drivers, maxWait) {
    let pPtr = 0; // Pointer for packages
    let dPtr = 0; // Pointer for drivers
    let matches = 0;

    while (pPtr < packages.length && dPtr < drivers.length) {
        const pkgTime = packages[pPtr];
        const drvTime = drivers[dPtr];

        if (drvTime < pkgTime) {
            // Driver arrived before package is ready
            dPtr++;
        } else if (drvTime > pkgTime + maxWait) {
            // Package waited longer than maxWait
            pPtr++;
        } else {
            // Valid match found
            matches++;
            pPtr++;
            dPtr++;
        }
    }

    return matches;
}
```

O(N + M), where N is the length of `packages` and M is the length of `drivers`. Each pointer moves forward at most once per step.

SPACE_COMPLEXITY:
O(1), as we only use two integer pointers and a counter variable.
