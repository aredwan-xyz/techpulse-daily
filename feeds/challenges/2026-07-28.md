PROBLEM:
In a reinforcement learning setting, you are given a dataset of historical interactions between agents and their environment. Each interaction has rewards, states, and actions associated with it. Your task is to compute the cumulative rewards for each action based on the states, following the principle of temporal difference learning. The goal is to create a function that updates the action-value estimates using the Q-learning algorithm.

You need to implement a function that takes in the dataset as a Pandas DataFrame and returns a summary DataFrame showing the cumulative rewards for each action. Each row in the input DataFrame corresponds to a unique interaction with the following columns: 'state', 'action', and 'reward'. 

The output DataFrame should display the average cumulative reward for each action, computed as the sum of rewards for all instances of that action in the dataset.

EXAMPLES:
Input:
```
import pandas as pd

data = {
    'state': ['s1', 's1', 's2', 's2', 's1', 's3'],
    'action': ['a1', 'a2', 'a1', 'a2', 'a1', 'a1'],
    'reward': [1, 2, 3, 1, 2, 0]
}
df = pd.DataFrame(data)
```
Output:
```
   action  avg_cumulative_reward
0     a1                     1.333333
1     a2                     1.500000
```
Explanation: Action 'a1' has a total reward of 1 + 2 + 3 + 0 = 6 across its three occurrences, leading to an average cumulative reward of 6/4 = 1.333. Action 'a2' has a total reward of 2 + 1 = 3 across its two occurrences, leading to an average cumulative reward of 3/2 = 1.500.

Input:
```
data = {
    'state': ['s1', 's2', 's3', 's3', 's1'],
    'action': ['a1', 'a2', 'a1', 'a1', 'a2'],

```
Output:

CONSTRAINTS:
- The dataset has at least 1 interaction and at most 10^6 interactions.
- The 'state' and 'action' are strings that can be any non-empty value.

HINT:
Consider using groupby operations in Pandas to calculate averages based on each action.

SOLUTION_PYTHON:
```python
import pandas as pd

def compute_avg_rewards(df):
    # Grouping by 'action' and calculating the cumulative reward mean
    avg_rewards = df.groupby('action')['reward'].mean().reset_index()
    # Renaming columns for clarity
    avg_rewards.columns = ['action', 'avg_cumulative_reward']
    return avg_rewards

# Example usage:
data = {
    'state': ['s1', 's2', 's3', 's3', 's1'],
    'action': ['a1', 'a2', 'a1', 'a1', 'a2'],
    'reward': [0, 5, 0, 3, 2]
}
df = pd.DataFrame(data)
print(compute_avg_rewards(df))
```

SOLUTION_JS:
```javascript
function computeAvgRewards(data) {
    const result = {};
    data.forEach(interaction => {
        const action = interaction.action;
        const reward = interaction.reward;

        if (!(action in result)) {
            result[action] = { total: 0, count: 0 };
        }
        result[action].total += reward;
        result[action].count += 1;
    });

    return Object.entries(result).map(([action, { total, count }]) => {
        return {
            action: action,
            avg_cumulative_reward: total / count
        };
    });
}

// Example usage:
const interactions = [
    { state: 's1', action: 'a1', reward: 0 },
    { state: 's2', action: 'a2', reward: 5 },
    { state: 's3', action: 'a1', reward: 0 },
    { state: 's3', action: 'a1', reward: 3 },
    { state: 's1', action: 'a2', reward: 2 }
];
console.log(computeAvgRewards(interactions));
```

TIME_COMPLEXITY: O(N)
SPACE_COMPLEXITY: O(A)

EXPLANATION:
The approach utilizes the `groupby` function in Pandas, which efficiently groups the data by action and calculates the mean of the rewards for each action. This is optimal since it processes each interaction only once, leading to linear time complexity relative to the number of interactions.
