TITLE: Case-Flip Toggle

DIFFICULTY: Easy
TOPIC: Arrays & Strings
ESTIMATED_TIME: 15 minutes

PROBLEM:
You are building a text processing module for a smart terminal interface. You are given a string `s` containing letters, numbers, symbols, and special toggle characters `'#'`.

Process the string from left to right according to the following rules:
1. Initially, the "case-flip" mode is turned OFF.
2. Every time a `'#'` character is encountered, the "case-flip" mode toggles (if it was OFF, it becomes ON; if it was ON, it becomes OFF).
3. While "case-flip" mode is ON, any alphabetical letter (A-Z, a-z) must have its case inverted (lowercase becomes uppercase, uppercase becomes lowercase). Non-alphabetical characters remain unchanged.
4. While "case-flip" mode is OFF, all characters retain their original casing.
5. All `'#'` toggle characters should be removed from the final output.

Return the processed string.

EXAMPLES:
Input: s = "hello#world#"
Output: "helloWORLD"
Explanation: 
- "hello" is processed while mode is OFF ("hello").
- The first '#' turns mode ON.
- "world" is processed while mode is ON ("WORLD").
- The second '#' turns mode OFF.

Input: s = "Code#ChAlLeNgE#2026"
Output: "CodecHaLlEnGe2026"
Explanation: 
- "Code" is processed while mode is OFF ("Code").
- First '#' turns mode ON.
- "ChAlLeNgE" is inverted to "cHaLlEnGe".
- Second '#' turns mode OFF.
- "2026" remains unchanged.

CONSTRAINTS:
- 1 <= s.length <= 10^5
- `s` consists of printable ASCII characters including uppercase/lowercase English letters, digits, punctuation, and `'#'`.

HINT:
Maintain a boolean flag to track whether the flip mode is currently active as you iterate through the string character by character.

def process_toggle_string(s: str) -> str:
    result = []
    flip_mode = False

        if char == '#':
            # Toggle the mode
