TITLE: Server Status Delta: Newly Activated Microservices
DIFFICULTY: Easy
TOPIC: Bit Manipulation
ESTIMATED_TIME: 10 minutes

PROBLEM:
A system administrator uses a 32-bit integer bitfield to monitor the status of microservices on a server network. Each bit position in the integer represents a specific microservice (bit set to `1` means the service is **running**, and `0` means it is **stopped**).

Given two 32-bit non-negative integers, `previous_status` and `current_status`, return the number of microservices that were **newly activated** (i.e., turned `ON` in `current_status` after being `OFF` in `previous_status`).

Services that were already running previously or services that stopped running should not be counted.

EXAMPLES:

Input: previous_status = 5, current_status = 14
Output: 2
Explanation: 
- `previous_status` = 5 (binary: ...00000101) -> Services at positions 0 and 2 were active.
- `current_status` = 14 (binary: ...00001110) -> Services at positions 1, 2, and 3 are active.
- Services at positions 1 and 3 were newly activated (switched from 0 to 1). Service 2 was already active, and Service 0 turned off.
- Total newly activated services = 2.

Input: previous_status = 7, current_status = 3
Output: 0
Explanation: 
- `previous_status` = 7 (binary: ...00000111)
- `current_status` = 3 (binary: ...00000011)
- No new services were turned on; service 2 was deactivated. Output is 0.

CONSTRAINTS:
- `0 <= previous_status <= 2^31 - 1`
- `0 <= current_status <= 2^31 - 1`

HINT:
You can find which bits are set in `current_status` but cleared in `previous_status` by combining the bitwise AND (`&`) and bitwise NOT (`~`) operators.

SOLUTION_PYTHON:
```python
def count_newly_activated(previous_status: int, current_status: int) -> int:
    """
    Finds the number of newly set bits in current_status compared to previous_status.
    """
    # Isolate bits that are 1 in current_status and 0 in previous_status
    newly_on = current_status & (~previous_status)
    
    # Count the number of set bits (popcount using Brian Kernighan's Algorithm)
    count = 0
    while newly_on > 0:
        newly_on &= (newly_on - 1)  # Clears the lowest set bit
        count += 1
        
    return count
```
