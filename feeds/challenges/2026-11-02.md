TITLE: Sparse Bit Jumper
DIFFICULTY: Easy
TOPIC: Bit Manipulation
ESTIMATED_TIME: [15 minutes]

PROBLEM:
You are building a game where a character jumps across energy platforms. The energy state of the character is represented as an unsigned 32-bit integer. A "Jump Power" metric is determined by counting the distance between the most significant set bit (the highest power of 2 present) and the least significant set bit (the lowest power of 2 present) in the integer's binary representation. 

Given an integer `n`, compute the distance between the highest set bit and the lowest set bit. If there is only one set bit or no set bits at all, return `0`.

EXAMPLES:
Input: n = 42
Output: 4
Explanation: 42 in binary is 101010. The highest set bit is at index 5 ($2^5 = 32$), and the lowest set bit is at index 1 ($2^1 = 2$). The distance is 5 - 1 = 4.

Input: n = 8
Output: 0
Explanation: 8 in binary is 1000. There is only one set bit, so the distance between the highest and lowest set bit is 0.

CONSTRAINTS:
- $0 \le n \le 2^{31} - 1$

HINT:
You can find the position of the lowest set bit using bitwise operations like `n & -n` or by trailing zeros, and the highest set bit by finding the most significant bit (or counting leading zeros).

SOLUTION_PYTHON:
```python
class Solution:
    def sparseBitJumper(self, n: int) -> int:
        if n <= 1:
            return 0
        
        # Find the position of the lowest set bit (trailing zeros)
        # Python's bit_length() gives 1-based index of highest bit
        # Alternatively, we can use built-in bit manipulation.
        
        highest = n.bit_length() - 1
        
        # Find the position of the lowest set bit using trailing zeros
        lowest = (n & -n).bit_length() - 1
        
        # If highest equals lowest, there's only 1 set bit
        if highest == lowest:
            return 0
            
        return highest - lowest

# Time Complexity: O(1)
# Space Complexity: O(1)
```

SOLUTION_JS:
```javascript
function sparseBitJumper(n) {
    if (n <= 1) return 0;

    // Find highest set bit position using 32-bit integer log2 equivalent
    let highest = 31 - Math.clz32(n);
    
    // Find lowest set bit using isolation
    let lowestBit = n & -n;
    let lowest = 31 - Math.clz32(lowestBit);

    if (highest === lowest) {
        return 0;
    }

    return highest - lowest;
}
```

TIME_COMPLEXITY: O(1)
SPACE_COMPLEXITY: O(1)

EXPLANATION:
The solution relies on finding the boundary positions of the set bits in constant time. For the highest set bit, we find the most significant bit index using built-in language primitives (`bit_length` in Python or `clz32` in JavaScript). For the lowest set bit, the standard bit manipulation trick `n & -n` isolates the rightmost set bit, and finding its position gives us our lower bound. Subtracting the two gives the exact distance required.

FOLLOW_UP:
What if instead of just the highest and lowest, you needed to find the maximum distance between *any* two adjacent set bits in the binary representation of `n`?
