PROMPT_TITLE: Comprehensive Defensive Code Security Audit & Remediation

THE_PROMPT:
You are a Senior Application Security Engineer conducting a defensive code review. Analyze the following {LANGUAGE} code for potential security vulnerabilities, compliance risks, and adherence to secure coding best practices (such as OWASP Top 10 and CWE standards).

Code to audit:
```{LANGUAGE}
{CODE_SNIPPET}
```

Context / Business Logic:
{CODE_CONTEXT}

Please format your response into the following structured sections:

1. **Executive Risk Summary**: Overall risk rating (Low, Medium, High, Critical) and brief summary of the security posture.
2. **Detailed Vulnerability Findings**: For every identified issue, include:
   - **Severity**: (Critical / High / Medium / Low / Informational)
   - **Classification**: Vulnerability type and standard reference (e.g., CWE-89 SQL Injection, CWE-79 XSS, Insecure Deserialization).
   - **Location**: Specific line(s) or logic flow affected.
   - **Technical Cause & Risk**: Explain why the code is vulnerable and the potential operational impact.
3. **Secure Code Remediation**: Provide a complete, production-ready, refactored code block that resolves all identified vulnerabilities using defense-in-depth patterns.
4. **Hardening & Prevention Recommendations**: List 2-3 additional security measures (e.g., static analysis integration, security headers, proper secrets management, framework-level protections).

Focus strictly on defensive analysis and code remediation. Do not include exploit payloads or functional attack vectors.

WHEN_TO_USE:
Use this prompt during pull request reviews, pre-deployment security checks, or legacy code audits to spot security flaws early. It is designed to help developers identify vulnerabilities rapidly and receive concrete, refactored code fixes.

EXAMPLE_INPUT:
{LANGUAGE}: Python / Flask
{CODE_SNIPPET}:
```python
@app.route('/search')
def search():
    query = request.args.get('q')
    sql = "SELECT * FROM products WHERE name LIKE '%" + query + "%'"
    results = db.engine.execute(sql)
    return render_template('search.html', results=results, query=query)
```
{CODE_CONTEXT}: Public web endpoint searching a SQL database for product listings and displaying results to users.

EXAMPLE_OUTPUT_SUMMARY:
Produces an executive risk rating (High) identifying an SQL Injection flaw (CWE-89) and a potential Cross-Site Scripting (XSS) risk depending on template rendering. It outputs fully remediated Python code utilizing parameterized queries and explicit output encoding, followed by advice on employing an ORM like SQLAlchemy.

PRO_TIPS:
- Supply complete functions or modules rather than single lines so the model can track data flows (sources to sinks).
- Mention your specific framework, database
