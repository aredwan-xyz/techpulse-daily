PROMPT_TITLE: API Blueprint Generator

THE_PROMPT:
You are an API design expert tasked with creating a clean and consistent API blueprint. Please provide details for the following API: 
- **API Name**: {API_NAME} 
- **Description**: {API_DESCRIPTION} 
- **Base URL**: {BASE_URL} 
- **Authentication Type**: {AUTH_TYPE} (e.g., OAuth2, API Key, etc.)
- **Endpoints**:
  1. Method: {METHOD} (GET, POST, PUT, DELETE)
     - URL: {ENDPOINT_URL}
     - Description: {ENDPOINT_DESCRIPTION}
     - Request Parameters: 
       - Name: {PARAM_NAME}, Type: {PARAM_TYPE}, Required: {REQUIRED}
     - Response Format: {RESPONSE_FORMAT}
     - Status Codes: {STATUS_CODES}
  2. (repeat for additional endpoints)

Your response should follow a structured format and ensure that best practices are adhered to for RESTful design, versioning, and documentation standards.

WHEN_TO_USE:
Use this prompt when you're developing a new API and need a blueprint that ensures clarity, consistency, and adherence to RESTful principles. It’s particularly useful during the initial design phases or when documenting existing APIs.

EXAMPLE_INPUT:
API Name: BookStore API  
Description: An API for managing online book sales  
Base URL: https://api.bookstore.com/v1  
Authentication Type: OAuth2  
Endpoints:  
1. Method: GET  
   URL: /books  
   Description: Retrieve a list of books  
   Request Parameters:  
     - Name: genre, Type: string, Required: no  
   Response Format: JSON  
   Status Codes: 200, 404  

EXAMPLE_OUTPUT_SUMMARY:
This prompt reliably produces a detailed API blueprint that includes essential elements such as endpoints, request parameters, response formats, and status codes. It ensures that the final design is clear and well-structured, making it easy for developers to implement and use.

PRO_TIPS:
- Be specific in your descriptions to minimize ambiguity.
- Include as many potential endpoints as you envision for comprehensive documentation.
- Consider future scalability in your design (e.g., versioning) to simplify updates later.

WORKS_WITH: Claude · GPT-4 · Gemini
