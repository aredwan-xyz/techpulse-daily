PROMPT_TITLE: Security Audit Code Review Checklist

THE_PROMPT:
As a security auditor, your task is to analyze the provided code snippet for potential security vulnerabilities. Please review the following code segment: `{CODE_SNIPPET}`. Consider the following aspects during your analysis:
1. **Authentication and Authorization**: Are there any flaws in user authentication procedures or privilege escalation vulnerabilities?
2. **Input Validation**: Is user input properly validated to prevent injection attacks, such as SQL injection, XSS, and others?
3. **Error Handling**: Does the code expose sensitive information through error messages or improper logging?
4. **Data Protection**: Are sensitive data elements such as passwords or personal information encrypted both at rest and in transit?
5. **Dependency Vulnerabilities**: Are third-party libraries used in this code up to date, and are there any known vulnerabilities in them?
6. **Best Practices**: Does the code follow established security best practices?

Provide a detailed report identifying vulnerabilities, their potential impact, and recommended remediation steps.

WHEN_TO_USE:
Use this prompt when you need a thorough examination of a codebase for security vulnerabilities. It's ideal for developers looking to ensure their code adheres to security best practices and is resilient against common threats.

EXAMPLE_INPUT:
CODE_SNIPPET: "function login(username, password) { // login logic here }"

EXAMPLE_OUTPUT_SUMMARY:
This prompt reliably produces a comprehensive analysis report that highlights vulnerabilities in the provided code snippet, their risk levels, and clear guidance on how to mitigate these risks. It often includes categorized findings, recommendations, and prioritizations for remediation efforts.

PRO_TIPS:
- Provide a concise but representative code snippet to get the most relevant analysis.
- Specify the programming language to tailor the review according to language-specific concerns.
- Mention any particular security standards or frameworks to align the audit with your organization's policies.
