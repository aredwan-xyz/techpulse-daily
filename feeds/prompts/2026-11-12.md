PROMPT_TITLE: The Performance Bottleneck Sniper

THE_PROMPT:
Act as a Senior Staff Software Engineer and Performance Architect. I am providing you with a codebase snippet or architectural overview that is currently underperforming: {CODE_OR_DESCRIPTION}. 

Your task is to conduct a "Performance Deep Dive." Please follow these steps:

1. **Bottleneck Identification:** Pinpoint the specific lines, algorithms, or architectural patterns causing latency, memory bloat, or CPU spikes. Explain *why* these are inefficient.
2. **Impact Assessment:** Estimate the performance cost (e.g., O(n²) complexity, blocking I/O, unnecessary re-renders).
3. **The Fix:** Provide a refactored version of the code that implements best practices for high-performance computing in {LANGUAGE_OR_FRAMEWORK}.
4. **Validation Strategy:** Suggest how I can benchmark this change to prove the improvement (e.g., specific profiling tools, telemetry metrics, or complexity analysis).

Ensure your recommendations prioritize readability while maintaining high-throughput efficiency. If multiple approaches exist, compare them briefly and recommend the most stable one.

WHEN_TO_USE:
Use this when you have a specific function or system component that is running slower than expected and you need a high-level technical audit. It is ideal for refactoring legacy code or optimizing critical paths before a production launch.

EXAMPLE_INPUT:
{CODE_OR_DESCRIPTION}: A Python function using a nested loop to compare two lists of 100,000 dictionaries to find common IDs.
{LANGUAGE_OR_FRAMEWORK}: Python 3.12

EXAMPLE_OUTPUT_SUMMARY:
The model will identify the O(n*m) complexity issue and provide a refactored solution using hash maps (sets/dicts) to achieve O(n+m) linear time. It will include a clear explanation of memory vs. time trade-offs and suggest using `cProfile` or `timeit` to verify the speedup.

PRO_TIPS:
- Include actual profiler logs or error stack traces in the input if you have them for surgical accuracy.
- Ask the model to "explain the trade-offs" if you are worried about the fix increasing memory consumption at the expense of speed.
- If the bottleneck involves database queries, specify the engine (e.g., PostgreSQL, MongoDB) in the language placeholder for schema-specific optimization tips.
