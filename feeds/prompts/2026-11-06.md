THE_PROMPT:
Act as a Principal Software Engineer specializing in root cause analysis and complex system debugging.

Diagnose the bug described below, pinpoint the exact failure point, and provide an optimized, production-ready fix.

### Context & Details
- **Tech Stack / Environment**: {LANGUAGE_STACK}
- **Expected Behavior**: {EXPECTED_BEHAVIOR}
- **Actual Behavior**: {ACTUAL_BEHAVIOR}
- **Error Logs / Stack Traces**: 
{ERROR_LOGS}

### Codebase Snippet

### Analysis & Output Instructions
Execute your analysis in the following structured steps:

1. **Root Cause Analysis (RCA)**: Explain *why* this error occurs at an execution and memory/state level. Highlight hidden edge cases, race conditions, or state mutations causing the failure.
2. **Hypothesis Ranking**: List the top 2-3 potential failure points, ranked from highest to lowest probability based on the stack trace.
3. **Corrected Code**: Provide the fully refactored, production-grade code fix. Include inline comments explaining structural changes and defensive coding guards.
4. **Verification Plan**: Provide 2-3 specific test cases (including edge cases) with actual test code to ensure the bug is resolved and regressions are prevented.
5. **Prevention Tip**: State one architectural or linting/static analysis rule to prevent this class of bug across the codebase.

WHEN_TO_USE:
Use this prompt when dealing with cryptic stack traces, race conditions, memory leaks, or silent failures across complex applications. It prevents AI models from giving band-aid fixes by forcing a structured Root Cause Analysis (RCA) before writing any solution code.

EXAMPLE_INPUT:
{LANGUAGE_STACK}: Node.js / TypeScript (Prisma ORM & Express)

{EXPECTED_BEHAVIOR}: User authentication endpoint updates the user's `lastLogin` timestamp and returns a JWT without locking the database connection under high concurrent load.

{ACTUAL_BEHAVIOR}: Under load test (>100 req/sec), requests hang indefinitely until throwing a connection pool timeout.

{ERROR_LOGS}: 
`PrismaClientKnownRequestError: Timed out fetching a new connection from the pool. Current pool limit: 10. Connection pool execution delay: 30005ms.`

{CODE_SNIPPET}:
```typescript
export async function handleLogin(req: Request, res: Response) {
  const { email, password } = req.body;
  
  return await prisma.$transaction(async (tx) => {
    const user = await tx.user.findUnique({ where: { email } });
    if (!user || !(await verifyPassword(password, user.hash))) {
      return res.status(401).json({ error: "Invalid credentials" });
    }
    
    // Send telemetry to external service
    await fetch("https://analytics.internal/api/log", {
      method: "POST",
      body: JSON.stringify({ userId: user.id })
    });

    await tx.user.update({
      where: { id: user.id },
      data: { lastLogin: new Date() }
    });

    const token = generateJwt(user);
    return res.json({ token });
  });
}
```
