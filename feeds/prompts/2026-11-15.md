PROMPT_TITLE: Clean Code Refactorer & Complexity Reducer

THE_PROMPT:
Act as a Senior Software Engineer and Clean Code Specialist. Your task is to refactor the provided code to maximize clarity, maintainability, and readability, without changing its functional behavior.

**Input Details:**
- **Language/Framework:** {LANGUAGE}
- **Code to Refactor:**
```
{CODE}
```
- **Context/Constraints:** {CONSTRAINTS}

**Refactoring Guidelines:**
1. **Reduce Cognitive Complexity:** Flatten deeply nested conditionals using guard clauses or early returns.
2. **Improve Naming:** Replace vague or single-letter variable/function names with self-documenting alternatives.
3. **Eliminate Duplication (DRY):** Extract repeated logic into helper functions or utilities.
4. **Enforce Single Responsibility (SRP):** Split large, multi-purpose functions into focused, single-task sub-functions.
5. **Modernize:** Use idiomatic, modern constructs appropriate for {LANGUAGE}.

**Required Output Format:**
1. **Refactored Code:** Provide the clean, production-ready implementation inside a single code block.
2. **Summary of Changes:** Bulleted list of key improvements made and the rationale behind each.
3. **Potential Risks:** Note any implicit assumptions made that should be validated with unit tests.

WHEN_TO_USE:
Use this prompt when working with legacy code, messy prototype implementations, or complex functions before submitting a Pull Request. It is ideal for reducing technical debt, removing code smells, and making codebase onboarding easier for your team.

EXAMPLE_INPUT:
**Language/Framework:** JavaScript (Node.js)

**Code to Refactor:**
```javascript
function processData(d, flag) {
  let result = [];
  if (d != null && d.length > 0) {
    for (let i = 0; i < d.length; i++) {
      if (d[i].status === 'active') {
        if (flag === true) {
          if (d[i].val > 100) {
            d[i].discount = d[i].val * 0.2;
            result.push(d[i]);
          } else {
            d[i].discount = d[i].val * 0.1;
            result.push(d[i]);
          }
        } else {
          d[i].discount = 0;
          result.push(d[i]);
        }
      }
    }
  }
  return result;
}
```

**Context/Constraints:** Must remain non-destructive to the original input objects if possible; performance on small arrays (<1000 items) is prioritized over raw micro-optimizations.

EXAMPLE_OUTPUT_SUMMARY:
The response provides a modernized JavaScript implementation using array methods (`filter`, `map`) and extracted helper functions to remove 4 levels of nested `if` statements. It includes explicit variable names (`items`, `applyDiscounts`), immutably copies objects to prevent side-effects, and details a list of changes explaining why guard clauses and functional iteration improved maintainability.

PRO_TIPS:
- Paste relevant unit tests alongside your prompt so the AI can verify edge cases remain intact.
- Specify exact target versions (e.g., "Python 3.12+" or "TypeScript 5.0") to get modern language features like pattern matching or tuple types.
- If you have strict company style guidelines (e.g., Airbnb, Google Style Guide), include that standard in the `{CONSTRAINTS}` placeholder.
