PROMPT_TITLE: Comprehensive Test Suite Generator

THE_PROMPT:
Generate a comprehensive test suite for the {APPLICATION_NAME} application. The test suite should cover the following areas: 
1. **Functionality**: Create unit tests for all critical functions in the system.
2. **Integration**: Write integration tests that verify the interactions between different modules and services.
3. **Performance**: Include performance tests that assess the application’s speed and resource usage under various conditions.
4. **Security**: Design security tests to identify vulnerabilities and ensure data protection.
5. **Usability**: Develop user acceptance tests that ensure the application meets user expectations and usability standards.

Make each test case clear and concise, specifying the purpose of the test, the expected outcome, and the steps to execute the test.

WHEN_TO_USE:
Use this prompt when you need a detailed, structured test suite for a specific application. It's especially useful for developers, QA engineers, or project managers who want to ensure thorough testing coverage before a release.

EXAMPLE_INPUT:
APPLICATION_NAME: "TaskMaster"

EXAMPLE_OUTPUT_SUMMARY:
This prompt consistently produces a detailed test suite that includes unit tests, integration tests, performance assessments, security checks, and usability evaluations. Each test case is presented with clear objectives and execution steps, ensuring easy implementation.

PRO_TIPS:
- Focus on clearly defining the functionality and features of your application when filling in the placeholder.
- Specify any requirements or constraints that should be considered in the test cases to tailor the output.
- Use real-world scenarios to make the usability tests more effective and relevant to end users.

WORKS_WITH: Claude · GPT-4 · Gemini
