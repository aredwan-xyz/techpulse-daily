PROMPT_TITLE: Scalable System Design Blueprint

THE_PROMPT:
You are an AI system architect tasked with designing a scalable system for {USE_CASE}. Create a detailed system design that includes the following components:
1. **Architecture Overview**: Describe the high-level architecture (e.g., microservices, monolith).
2. **Components**: List the main components required, such as databases, APIs, load balancers, etc.
3. **Scalability Strategy**: Explain how the system will handle increased load over time. Include both vertical and horizontal scaling strategies.
4. **Performance Considerations**: Outline any performance optimization techniques you will implement, such as caching and data partitioning.
5. **Security Measures**: Detail the security practices to protect data and ensure user privacy.
6. **Monitoring and Maintenance**: Describe tools and practices for system monitoring, logging, and maintenance routines.

WHEN_TO_USE:
Use this prompt when you need help designing a scalable system architecture that needs to accommodate growth. It's ideal for software engineers, product managers, or tech entrepreneurs who want a comprehensive view of system design requirements.

EXAMPLE_INPUT:
- Use case: A video streaming platform that accommodates millions of concurrent users.

EXAMPLE_OUTPUT_SUMMARY:
This prompt reliably produces a well-structured system design document that covers architecture, key components, scalability strategies, performance optimization, security, and maintenance suggestions tailored to the use case provided. It provides a comprehensive roadmap for building a scalable system.

PRO_TIPS:
- Clearly define your use case to get more focused and relevant results.
- Specify any particular technologies or constraints if you have them.
- Use follow-up prompts to dive deeper into specific components discussed in the output.
