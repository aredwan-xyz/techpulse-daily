PROMPT_TITLE: Elevate My Code - Senior Review

THE_PROMPT:
As a senior engineer, I would like your expert analysis on the following code snippet. Please review the code for best practices, potential bugs, performance optimization, and overall readability. Provide specific suggestions for improvement. Here’s the code: 
```
{CODE_SNIPPET}
```
Additionally, please explain your reasoning behind each suggestion. If possible, relate your feedback to industry standards or experiences that may improve my understanding.

WHEN_TO_USE:
Use this prompt when you have a piece of code that you want to get reviewed by a senior engineer. It’s ideal for enhancing the quality of your project, learning best coding practices, or when you're facing specific challenges in your code that need expert insight.

EXAMPLE_INPUT:
```
def calculate_total(price, tax_rate):
    total = price + (price * tax_rate)
    return total
```

EXAMPLE_OUTPUT_SUMMARY:
This prompt reliably produces detailed feedback from a senior engineer on the given code snippet. It includes insights on best practices, potential edge cases, and suggestions for improving performance and readability. The engineer’s reasoning will aid in deepening your understanding of coding standards.

PRO_TIPS:
- Provide a concise yet informative background of your code’s purpose to give context to the reviewer.
- Include specific areas where you feel uncertain to get targeted feedback.
- Be open to constructive criticism and willing to ask follow-up questions for clarification.

WORKS_WITH: Claude · GPT-4 · Gemini
