PROMPT_TITLE: Comprehensive Code Performance Auditor

THE_PROMPT:
Act as a Principal Performance Engineer. Analyze the provided {LANGUAGE_OR_FRAMEWORK} code snippet for performance bottlenecks, memory leaks, and scalability issues.

Target Code:
{CODE_SNIPPET}

Context & Constraints:
- Expected load/scale: {EXPECTED_LOAD}
- Performance goals (e.g., latency, throughput): {PERFORMANCE_GOALS}

Provide your analysis in the following structured format:

1. BOTTLENECK IDENTIFICATION: List every performance issue, ordered by severity. Explain the root cause and the complexity (Big-O time and space) of the current implementation.
2. REFACTORED CODE: Provide the optimized, production-ready code implementing best practices for {LANGUAGE_OR_FRAMEWORK}.
3. BENCHMARK & TESTING STRATEGY: Recommend specific profiling tools, micro-benchmarking approaches, or load tests to validate the fix.
4. TRADE-OFFS: Briefly note any trade-offs introduced by the optimization (e.g., increased memory usage for faster execution time).

WHEN_TO_USE:
Ideal for reviewing critical loops, database query handlers, or algorithms before pushing to production. Use this when your application is experiencing high latency, excessive CPU usage, or memory bloat under load.

EXAMPLE_INPUT:
LANGUAGE_OR_FRAMEWORK: Python / Pandas
CODE_SNIPPET: 
```python
import pandas as pd

def process_data(file_path):
    df = pd.read_csv(file_path)
    results = []
    for index, row in df.iterrows():
        if row['status'] == 'active':
            val = row['price'] * 1.15
            results.append({'id': row['id'], 'new_price': val})
    return pd.DataFrame(results)
```
EXPECTED_LOAD: 500,000 rows per file, run hourly.
PERFORMANCE_GOALS: Reduce execution time from ~45 seconds to under 2 seconds.

EXAMPLE_OUTPUT_SUMMARY:
The prompt reliably delivers a prioritized breakdown of inefficiencies (like avoiding slow `iterrows`), a drop-in vectorized Pandas replacement that executes exponentially faster, and a clear guide on how to benchmark the improvement.

PRO_TIPS:
- Include hardware or memory constraints in the context if you are running on restricted environments (e.g., AWS Lambda).
- Paste relevant database schemas or API payloads alongside the code for deeper context-aware optimization.
- Ask the AI to write a unit test or benchmark script comparing the old vs. new implementation.
