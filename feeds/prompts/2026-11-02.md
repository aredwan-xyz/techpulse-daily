PROMPT_TITLE: Comprehensive Test Suite Generator

THE_PROMPT:
You are an expert QA Engineer and testing specialist. Generate a robust, production-ready test suite for the following code or feature: {CODE_OR_FEATURE}.

To ensure comprehensive coverage, structure your output into the following sections:
1. **Unit Tests**: Test individual functions, methods, and edge cases (e.g., null inputs, boundary values, unexpected data types).
2. **Integration Tests**: Test interactions between components, modules, or external services (mocking external APIs where necessary).
3. **End-to-End (E2E) / Functional Tests**: Test critical user journeys and complete workflows from start to finish.
4. **Security & Performance Tests**: Identify potential vulnerabilities (e.g., injection, overflow) and performance bottlenecks.

Use the testing framework: {TESTING_FRAMEWORK}. 
Ensure all tests include clear descriptions, proper setup/teardown, descriptive assertions, and handle both positive and negative test cases.

WHEN_TO_USE:
Ideal for developers looking to achieve high test coverage quickly on new features, legacy refactoring, or critical business logic. It works exceptionally well when you need to brainstorm edge cases you might have otherwise missed.

EXAMPLE_INPUT:
CODE_OR_FEATURE: A user registration function that validates email formats, enforces password strength (min 8 chars, 1 number, 1 special char), hashes passwords using bcrypt, and saves the user to a PostgreSQL database while sending a welcome email via SendGrid.
TESTING_FRAMEWORK: Jest & Supertest

EXAMPLE_OUTPUT_SUMMARY:
This prompt reliably produces a well-structured, comprehensive markdown output containing unit tests for regex validation and hashing, integration tests for database persistence with mocks, API endpoint tests for HTTP responses, and edge cases for duplicate emails or service timeouts.

PRO_TIPS:
- Specify the exact testing library or framework version if your project uses unique dependencies.
- Mention specific error-handling requirements or business logic constraints within your code description for tailored test scenarios.
- Ask the prompt to include coverage threshold targets if you are enforcing strict CI/CD pipelines.

WORKS_WITH: Claude · GPT-4 · Gemini
