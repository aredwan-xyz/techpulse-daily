## 🎯 The Core Idea (2 sentences)
This paper introduces LARC, a framework that lets multimodal AI models reason about image generation using continuous hidden states instead of forcing text into discrete tokens. This bridges the gap between text-based reasoning and image creation, unlocking better scaling and control.

## 🔍 The Problem They Solved (2 sentences)
Current multimodal models struggle to apply step-by-step reasoning to image generation because text uses discrete tokens while images live in a continuous space. This mismatch prevents image generators from benefiting from the kind of deep, test-time reasoning and fine-grained control that make large language models so powerful.

## 💡 The Key Innovation (2-3 sentences)
Instead of translating thoughts strictly into words before drawing, LARC performs "latent reasoning" directly in the continuous vector space shared by text and images. By removing the rigid token-level bottleneck, the model can think fluidly using internal representations that naturally suit both language logic and visual synthesis.

## 🛠️ Why Developers Should Care (2 sentences)
It paves the way for text-to-image and multimodal models that can genuinely "think before they draw" at inference time, leading to more accurate and controllable generations. Developers will soon be able to scale inference compute for image tasks just like we currently do with reasoning LLMs.

## ⚡ TL;DR
By letting AI models think in continuous vectors rather than rigid words, this paper finally allows text-based reasoning to supercharge image generation.
