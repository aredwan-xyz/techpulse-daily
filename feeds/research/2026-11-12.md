## 🎯 The Core Idea
TorchCurves is a Python library that lets you use smooth mathematical curves (like splines) as trainable building blocks inside PyTorch models. It allows neural networks to easily learn and adjust the shapes of curves during training, just like standard neural network weights.

## 🔍 The Problem They Solved
Emerging neural network designs (like Kolmogorov-Arnold Networks) rely heavily on continuous math curves, but integrating these curves into standard deep learning workflows has been awkward and fragmented. Developers often had to choose between slow pure-Python implementations or complex, hard-to-maintain custom C++/CUDA kernels.

## 💡 The Key Innovation
TorchCurves implements classic curve algorithms (such as B-splines and Legendre polynomials) directly using standard vectorized PyTorch operations, completely avoiding low-level custom GPU code. It provides end-to-end automatic differentiation, meaning gradients flow smoothly through both the inputs to the curves and the parameters that define their shapes.

## 🛠️ Why Developers Should Care
You can now build and experiment with curve-based architectures, dynamic embeddings, or functional regression models using clean, readable PyTorch code. Because it uses native PyTorch under the hood, it integrates seamlessly with existing training pipelines without compiler headaches or hardware lock-in.

## ⚡ TL;DR
TorchCurves makes smooth math curves plug-and-play building blocks in standard PyTorch, without needing custom GPU code.

## 📝 Original Abstract

> We present TorchCurves, a PyTorch library that treats vector-valued parametric curves as learnable primitives. Its central operation maps batches of scalar inputs to points on curves represented in B-spline or Legendre polynomial bases, with differentiation through both inputs and coefficients. Curve coefficients can be optimized jointly with the surrounding model or produced by another network. The library provides trainable modules, reusable basis modules, and a functional interface, supporting applications ranging from continuous feature embeddings to Kolmogorov-Arnold networks and functional regression.
