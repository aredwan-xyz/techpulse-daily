# Developer Market Pulse: November 8, 2026

Analyzing the latest hiring postings from November's *Ask HN: Who is hiring right now?* thread alongside cross-platform job board telemetry yields clear signals: companies are aggressively cutting legacy tech debt and doubling down on low-latency AI infrastructure, multi-agent execution frameworks, and evaluation pipelines.

---

## 🔥 Hottest Skills Right Now

1. **Model Context Protocol (MCP) & Agent Tools**: Standardizing LLM tool-calling and API interfaces. Engineering teams are actively replacing custom integrations with standardized MCP servers.
2. **Rust for AI Infrastructure**: Essential for low-level memory efficiency, fast-path inference wrappers, and custom vector storage engines where Python runtime overhead is unacceptable.
3. **Triton & CUDA Kernel Tuning**: As model sizes stabilize, companies are aggressively optimizing inference latency and token throughput to reduce raw cloud compute overhead.
4. **GraphRAG & HyDE Retrieval**: Simple semantic vector search is no longer enough for enterprise applications. Knowledge graph hybrid pipelines and Hypothetical Document Embeddings (HyDE) are standard requirements.
5. **TypeScript + Streaming UX Architecture**: AI interfaces demand real-time streaming updates, optimistic UI states, and complex canvas interfaces (e.g., dynamic agent observability graphs).

---

## 💰 Salary Signals

* **Staff AI Infrastructure Engineer (US Remote)**: **$255,000 – $340,000 base** + significant equity. High-throughput serving and low-latency system optimizations command the highest premium in current listings.
* **Senior Agentic Systems Engineer**: **$210,000 – $275,000 base**. High demand for engineers capable of engineering deterministic fallback loops and reliable multi-step tool execution.
* **Senior Full-Stack Developer (Generalist)**: **$155,000 – $195,000 base**. Base salary bands have stabilized at lower historical levels for classic CRUD generalists without embedded AI or systems expertise.
