## 📄 Rethinking Neural Thickets Without Weight Perturbations

**Authors:** Nicolas Dufour, Elouan Gardès, Amil Dravid, Patrick Pérez et al.
**Published:** 2026-10-29
**arXiv ID:** [2610.40649v1](https://arxiv.org/abs/2610.40649v1)

[![Read Paper](https://img.shields.io/badge/Read_Paper-arXiv-B31B1B?style=flat-square&logo=arxiv)](
https://arxiv.org/abs/2610.40649v1)
[![PDF](https://img.shields.io/badge/Download_PDF-B31B1B?style=flat-square&logo=adobe)](
https://arxiv.org/pdf/2610.40649v1)

---

## 🎯 The Core Idea
The researchers debunked a complex theory that claimed adding random noise to an AI’s internal weights uncovers hidden "expert" models. Instead, they show that simply adding random noise to the model's final output scores achieves the exact same reasoning boost with far less effort.

## 🔍 The Problem They Solved
A recent popular hypothesis suggested that language models hide dense clusters of task experts deep within their weight geometry, requiring compute-heavy modifications to internal parameters to unlock them. This led engineers to believe that complex, full-model weight manipulation was necessary to squeeze out extra reasoning performance.

## 💡 The Key Innovation
The authors proved that these gains have nothing to do with deep weight magic, but rather with basic ensembling: generating varied predictions, picking the best candidates on a small test set, and letting them vote. In fact, leaving the model completely frozen and lightly shaking up the final output predictions (the logits) matched or beat modifying the actual weights across multiple reasoning tasks. They formalized this lightweight approach into a simple recipe called **Perturb-Select-Vote (PSV)**.

## 🛠️ Why Developers Should Care
You don’t need to clone massive model checkpoints in GPU memory or hack internal weights to get the accuracy boost of model ensembling. You can get identical performance gains purely through black-box techniques by injecting slight randomness into the final outputs of a frozen model via standard APIs.

## ⚡ TL;DR
You don't need to mess with an AI's internal wiring to get better answers—just slightly scramble its final guesses, pick

# uv

**Category:** Dev Tools
**Link:** [https://github.com/astral-sh/uv](https://github.com/astral-sh/uv)

[![Repo](https://img.shields.io/badge/View_on_GitHub-181717?style=flat-square&logo=github)](

---

## What Is It?
`uv` is an extremely fast, single-binary Python package and project manager written in Rust by Astral (the creators of Ruff). It serves as a unified replacement for `pip`, `pip-tools`, `virtualenv`, `poetry`, and `pyenv`.

## The Problem It Solves
Python dependency management and environment setup has historically been fragmented, confusing, and agonizingly slow. Developers juggled three to four separate tools just to manage Python versions, lock dependencies, and isolate environments, often watching CI pipelines crawl while wheel dependencies resolved. `uv` consolidates the entire workflow into a single tool that executes nearly instantaneously.

## Why It's Worth 10 Minutes of Your Time
- **Absurd speed**: It resolves and installs packages 10–100x faster than `pip` and `poetry`, relying on aggressive global caching and parallelized Rust network/disk operations.
- **Python version management included**: You don't need `pyenv` anymore; `uv` automatically downloads, installs, and manages isolated Python runtimes (e.g., `uv python install 3.12`).
- **Zero-setup script runner**: You can execute self-contained Python scripts declaring their own inline dependencies without manually creating or activating a virtualenv.

## Quick Start
```bash
# Install uv (macOS/Linux)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Initialize a project and add a dependency
uv init my-project && cd my-project
uv add requests

# Run inside the automatically managed virtualenv
uv run python main.py
```

## Real-World Example
Run a self-contained script with inline dependency declarations (PEP 723)—`uv` provisions an ephemeral environment and runs it in milliseconds:

```python
# /// script
# requires-python = ">=3.11"
# dependencies = [
#     "httpx",
#     "rich",
# ]
# ///

import httpx
from rich import print

data = httpx.get("https://api.github.com/repos/astral-sh/uv").json()
print(f"[bold green]Stars:[/bold green] {data['stargazers_count']}")
```

Run it directly from the terminal without activating a virtual environment:
```bash
uv run script.py
```
