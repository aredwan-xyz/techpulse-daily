## 📄 3D-Aware VLMs with Implicit and Explicit Geometries

## 🎯 The Core Idea
The researchers developed a new framework called VLM-IE3D that improves how vision-language models (VLMs) understand 3D spaces by using data from RGB videos. It combines both basic and detailed geometric information to enhance spatial reasoning in AI.

## 🔍 The Problem They Solved
Before this work, most vision-language models relied solely on 2D images, which limited their capability to perform tasks requiring an understanding of 3D environments. This lack led to inaccuracies in applications like scene interpretation or navigating virtual spaces.

## 💡 The Key Innovation
VLM-IE3D introduces two types of geometric representations: Implicit Geometry Tokens (IGTs) that capture general geometric features from videos, and Explicit Geometry Tokens (EGTs) that provide detailed structural information from 3D reconstructions. This innovative combination, along with a dedicated 3D-aware adapter, allows the model to better integrate 2D and 3D insights, leading to improved performance in spatial tasks.

## 🛠️ Why Developers Should Care
This paper presents a method that enhances AI’s ability to reason about and interact with 3D environments, making it highly relevant for developers working on applications like augmented reality, robotics, or any system that involves understanding spatial contexts. By incorporating both implicit and explicit geometry, developers can create smarter models that perform better in complex visual tasks.

## ⚡ TL;DR
A new AI framework improves how machines understand 3D spaces by blending video insights and detailed geometric information.

## 💡 Coding Challenge


TITLE: Inventory Stock Tracker
DIFFICULTY: Medium
TOPIC: Sorting & Searching
ESTIMATED_TIME: 30 minutes

PROBLEM:
You are tasked with developing a stock inventory system for a warehouse. Each item in the inventory has a unique identifier and a quantity. Your goal is to implement a function that efficiently retrieves the top K items with the highest quantities from the inventory list. The function should accept a list of tuples, where each tuple represents an item (identifier, quantity). If two items have the same quantity, return them in alphabetical order based on their identifiers.

EXAMPLES:
Input: 
```python
inventory = [("itemA", 5), ("itemB", 2), ("itemC", 5), ("itemD", 3)]
K = 2
```
Output: 
```python
[("itemA", 5), ("itemC", 5)]
```
Explanation: Both itemA and itemC have the highest quantity of 5. Since both items have the same quantity, they are returned in alphabetical order.

Input: 
```python
inventory = [("itemE", 1), ("itemF", 4), ("itemG", 4), ("itemH", 4)]
K = 3
```
Output: 
```python
[("itemF", 4), ("itemG", 4), ("itemH", 4)]
```
Explanation: ItemF, ItemG, and ItemH all have the same quantity of 4, which is the highest. Since we need to return the top three, we include all of them.

CONSTRAINTS:
- 1 <= len(inventory) <= 10^5
- 1 <= K <= len(inventory)

HINT:
Consider using a sorting algorithm to rank the items based on their quantities and identifiers to find the top K items.

SOLUTION_PYTHON:
```python
def top_k_items(inventory, K):
    # Sort inventory by quantity (descending) and by identifier (ascending)
    sorted_inventory = sorted(inventory, key=lambda x: (-x[1], x[0]))
    # Return the top K items
    return sorted_inventory[:K]

# Sample Usage
inventory = [("itemA", 5), ("itemB", 2), ("itemC", 5), ("itemD", 3)]
K = 2
print(top_k_items(inventory, K))  # Output: [('itemA', 5), ('itemC', 5)]
```

SOLUTION_JS:
```javascript
function topKItems(inventory, K) {
    // Sort the inventory based on quantity and identifier
    inventory.sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]));
    // Return the first K items
    return inventory.slice(0, K);
}

// Sample Usage
const inventory = [["itemA", 5], ["itemB", 2], ["itemC", 5], ["itemD", 3]];
const K = 2;
console.log(topKItems(inventory, K));  // Output: [['itemA', 5], ['itemC', 5]]
```

TIME_COMPLEXITY: O(n log n)
SPACE_COMPLEXITY: O(n)

EXPLANATION:
The approach involves sorting the inventory list based on two criteria: the quantity in descending order and the identifier in ascending order. This double sorting ensures that ties in quantities resolve in favor of alphabetical order. After sorting, we return the first K elements from the sorted list, which are the highest in terms of quantity.

FOLLOW_UP:
What changes would you make to the solution if you needed to support real-time inventory updates, such that you can efficiently add or remove items from the inventory while still being able to quickly retrieve the top K items?

# Zellij

**Category:** CLI
**Link:** [https://github.com/zellij-org/zellij](https://github.com/zellij-org/zellij)

[![Repo](https://img.shields.io/badge/View_on_GitHub-181717?style=flat-square&logo=github)](
https://github.com/zellij-org/zellij)

---

## What Is It?
Zellij is a modern terminal workspace with a focus on usability, extensibility, and a pleasant user experience, allowing developers to run and manage multiple terminal sessions side by side.

## The Problem It Solves
Before Zellij, developers often juggled multiple terminal windows or tabs, leading to a cluttered workspace and decreased productivity. Traditional terminal multiplexers like tmux offer power but can be intimidating and complicated for newcomers. Zellij tackles these challenges with a user-friendly interface and out-of-the-box support for layouts, making it easier to manage workflows.

## Why It's Worth 10 Minutes of Your Time
1. **Intuitive User Interface**: Zellij provides a visually appealing and easy-to-navigate layout manager, reducing the learning curve compared to tmux or screen.
2. **Workspace Management**: With support for predefined layouts and the ability to create custom ones, you can instantly switch between different configurations tailored to different tasks.
3. **Plugin Ecosystem**: Zellij has a built-in system for plugins. This extensibility allows you to enhance your terminal experience with additional features tailored to your workflow.

## Quick Start
```bash
# Install Zellij via a package manager (e.g., Homebrew for macOS)
brew install zellij

# Start Zellij
zellij
```

## Real-World Example
```rust
# Sample layout configuration in Zellij
{
    "layout": {
        "panes": [
            {
                "direction": "top",
                "size": 50,
                "command": "bash"
            },
            {
                "direction": "bottom",
                "size": 50,
                "command": "htop"
            }
        ]
    }
}
```
This snippet shows how you might define a layout with a Bash pane on top and an htop pane below, allowing for easy resource monitoring while coding.

## Who Should Use It
✅ Perfect for: Developers who manage multiple terminal sessions, want an easy-to-use alternative to traditional terminal multiplexers, or are looking for a customizable and extensible terminal app.  
⏩ Skip if: You prefer a minimal setup and do not want additional layers of complexity, or if you are deeply embedded in a specific tmux workflow.

## The Honest Take
Zellij makes terminal management more accessible and visually appealing for users accustomed to a GUI while still catering to power users with its plugin infrastructure. However, if you're already comfortable with a tool like tmux, transitioning might not yield enough benefit to justify the switch. Overall, Zellij is a promising choice for developers looking to enhance their terminal experience.
