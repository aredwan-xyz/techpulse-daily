## 📄 3D-Aware VLMs with Implicit and Explicit Geometries

**Authors:** Wenhao Li, Xueying Jiang, Quanhao Qian, Deli Zhao et al.
**Published:** 2026-07-23

## 🎯 The Core Idea
This paper introduces VLM-IE3D, a new system that helps visual language models (VLMs) better understand 3D space by using both implicit and explicit geometry derived from videos. By combining high-level and detailed geometric information, the model improves its performance on 3D tasks.

## 🔍 The Problem They Solved
Previous vision-language models relied heavily on 2D images, which limited their ability to perform tasks requiring deep spatial reasoning in three dimensions. This lack of 3D understanding made it challenging for these models to interact with and interpret the complex spatial relationships found in the real world.

## 💡 The Key Innovation
The novel approach introduced in this paper is the use of two types of geometry tokens: Implicit Geometry Tokens (IGTs) and Explicit Geometry Tokens (EGTs). IGTs provide general geometric insights from videos, while EGTs offer specific 3D structures, and the paper presents an adapter that smartly merges these representations with traditional 2D visual cues to enhance the model's spatial awareness.

## 🛠️ Why Developers Should Care
By integrating 3D spatial awareness directly into VLMs, developers can create AI systems that perform better in tasks requiring spatial understanding, such as robotics and augmented reality applications. This advancement could lead to more intuitive and effective AI interactions in 3D environments, improving user experience significantly.

## ⚡ TL;DR
Researchers created a new AI model that improves 3D understanding by combining information from videos, making it better at tasks that require spatial reasoning.

## 💡 Coding Challenge


TITLE: Minimum String Temperature
DIFFICULTY: Hard
TOPIC: Stack & Queue
ESTIMATED_TIME: 45 minutes

PROBLEM:
You are tasked with analyzing temperature measurements given as a string of integers, where each integer represents a temperature in degrees Celsius. Your goal is to efficiently find the minimum temperature that occurs after any point in the input string until the end. You can process the input string one character at a time and must maintain the order of the temperatures while doing so.

Create a class `TemperatureAnalyzer` that has the following methods:
1. `add_temperature(temperature: str)`: Takes a string representing a single temperature and stores it in the processor.
2. `get_minimum() -> str`: Returns the minimum temperature added so far as a string. If no temperatures have been added yet, return "No temperatures".

Your implementation should be efficient in terms of both time and space.

EXAMPLES:
Input: `TemperatureAnalyzer()`, `add_temperature("30")`, `add_temperature("25")`, `add_temperature("35")`, `get_minimum()`
Output: "25"
Explanation: The minimum value among the temperatures added is 25.

Input: `TemperatureAnalyzer()`, `get_minimum()`
Output: "No temperatures"
Explanation: No temperatures have been added yet.

CONSTRAINTS:
- Temperatures will always be valid string representations of integers, and will be in the range of -50 to 50 inclusive.
- You may call the `add_temperature` method up to 10^6 times.

HINT:
Think about how to maintain the order of input while efficiently retrieving the minimum temperature at any given point.

SOLUTION_PYTHON:
```python
class TemperatureAnalyzer:
    def __init__(self):
        self.temperatures = []  # This stack holds all the temperatures
        self.min_stack = []  # This stack keeps track of minimum temperatures

    def add_temperature(self, temperature: str):
        temp = int(temperature)
        self.temperatures.append(temp)
        
        # Push to min_stack if it's empty or current temperature is less than or equal to
        if not self.min_stack or temp <= self.min_stack[-1]:
            self.min_stack.append(temp)

    def get_minimum(self) -> str:
        if not self.min_stack:
            return "No temperatures"
        return str(self.min_stack[-1])  # Return the current minimum

# Time Complexity: O(1) for get_minimum, O(1) amortized for add_temperature
# Space Complexity: O(n) to store temperatures
```

SOLUTION_JS:
```javascript
class TemperatureAnalyzer {
    constructor() {
        this.temperatures = []; // Array to hold temperatures
        this.minStack = []; // Array to maintain minimum temperatures
    }

    add_temperature(temperature) {
        const temp = parseInt(temperature);
        this.temperatures.push(temp);
        
        // Push to minStack if it's empty or current temperature is less than or equal to
        if (this.minStack.length === 0 || temp <= this.minStack[this.minStack.length - 1]) {
            this.minStack.push(temp);
        }
    }

    get_minimum() {
        return this.minStack.length === 0 ? "No temperatures" : this.minStack[this.minStack.length - 1].toString();
    }
}

// Time Complexity: O(1) for get_minimum, O(1) amortized for add_temperature
// Space Complexity: O(n) to store temperatures
```

TIME_COMPLEXITY: O(1)
SPACE_COMPLEXITY: O(n)

EXPLANATION:
This approach uses two stacks: one to store the temperatures and another to track the minimum temperatures. Every time a new temperature is added, it is compared against the current minimum; if it is lower or the same, it is added to the min stack. This allows the `get_minimum` method to run in constant time, making the overall solution efficient and optimal for large inputs.

FOLLOW_UP:
What would happen if you wanted to keep track of the maximum temperature as well? How would you adjust your implementation?

# Starship

**Category:** CLI
**Link:** [https://github.com/starship/starship](https://github.com/starship/starship)

[![Repo](https://img.shields.io/badge/View_on_GitHub-181717?style=flat-square&logo=github)](
https://github.com/starship/starship)

---

## What Is It?
Starship is a minimal, blazing-fast prompt for your shell that displays information about your current directory, Git status, and more, in a visually appealing way.

## The Problem It Solves
Before Starship, many developers relied on basic terminal prompts that provided limited information and were often cluttered or outdated. This lack of context led to wasted time navigating directories and checking the status of projects. Starship simplifies this process by integrating essential information directly into your prompt, making it easier to focus on coding rather than managing the terminal.

## Why It's Worth 10 Minutes of Your Time
1. **Highly Customizable**: Starship allows you to customize your prompt with a variety of modules, such as Git branch display, Node.js version, or Python virtual environment status. You can tailor it to show the information you care about most.
2. **Cross-Shell Compatibility**: Whether you use Bash, Zsh, PowerShell, or Fish, Starship works seamlessly across all major shells, reducing the friction of switching environments or collaborating with team members using different setups.
3. **Performance Focused**: Built in Rust, Starship is designed to minimize latency. You won’t experience lag in your prompt, even when switching between heavily populated directories or git repositories.

## Quick Start
```bash
curl -sS https://starship.rs/install.sh | sh
```
Then, add the following line to your shell profile (e.g. `~/.bashrc`, `~/.zshrc`):
```bash
eval "$(starship init zsh)"
```

## Real-World Example
```bash
# In your terminal, navigate to a Git repository
cd ~/my-project

# Your prompt might show:
# ➜ my-project (main) 3.1.0
```
This example shows the project name, current branch, and package version, all at a glance.

## Who Should Use It
✅ Perfect for: Developers who rely on the terminal frequently, want a sleek and informative command prompt, or need to manage multiple languages and tools in their workflow.  
⏩ Skip if: You prefer a traditional and minimal prompt or are using simple command-line interfaces where prompt information isn’t necessary.

## The Honest Take
Starship delivers a beautiful and functional prompt experience that can significantly enhance productivity in the terminal environment. While the learning curve for customization might be a tad steep for beginners, the effort pays off with a more insightful command-line experience. Overall, it's a strong recommendation for anyone looking to modernize their shell usage.
